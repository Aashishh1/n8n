  <h1>🚀 AI-Powered Game Generator</h1> 
</div>

This project allows users to generate **fully executable 2D & 3D Python games** instantly using **AI + Workflow Automation**.  
Built as part of my **AI Automation & Workflow learning**, this system converts a simple game idea into a **ready-to-run Python game** — **with zero manual coding**.

---

## 🎯 Objective

The main objective of this project is to **automate game creation using AI**, including:

- 🧠 Converting text prompts into game logic  
- 🎮 Auto-generating 2D & 3D Python games  
- ⚙️ Automating backend workflow using n8n  
- 💾 Delivering instant runnable game files  

---

## 🧩 Workflow Overview

### ✨ 1. Prompt-Based Game Idea Input

A **Streamlit Web App** is used to collect user game ideas such as:

| 🎮 Game Type | 📝 Example Prompt |
|-------------|------------------|
| **2D Games** | 2D car dodging game |
| **3D Games** | 3D space shooter game |

---

### ⚙️ 2. AI-Based Game Code Generation

- 🤖 User prompt is sent to **n8n Webhook**
- 🧠 **Gemini AI** generates complete Python game code
- 🛡️ Ensures:
  - Clean & executable code  
  - No external assets  
  - Correct game engine selection  

---

### 🔍 3. Smart Engine Selection Logic

The AI automatically selects the game engine:

| 🎯 Game Dimension | 🎮 Engine Used |
|------------------|--------------|
| **2D Games** | Pygame |
| **3D Games** | Panda3D |

---

### 📩 4. Instant Game File Generation

- 📄 Generated code is saved as `app_code.py`
- ⚡ User can instantly run the game locally
- 🔁 No manual changes required

---
