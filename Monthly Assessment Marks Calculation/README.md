  <h1> Monthly Assessment Marks Calculation</h1> 
</div>

This project automates the **monthly assessment evaluation process for students** as part of my **Automation learning at Innomatics Research Labs**.  
Using **n8n Workflow Automation**, I built an end-to-end system that calculates average marks, evaluates placement eligibility, and sends instant automated feedback — **without any manual intervention**.

---

## 🎯 Objective

The main goal of this project is to **automate the student assessment workflow**, including:

- 📥 Collecting module-wise assessment scores  
- 🧮 Calculating average marks automatically  
- 🎓 Evaluating placement eligibility  
- 📩 Sending instant personalized feedback to students  

---

## 🧩 Workflow Overview

### ✨ 1. Form-Based Input Collection

An **n8n Form** is used to collect module-wise assessment marks for:

| 🎓 Student Category | 📚 Modules Covered |
|--------------------|-------------------|
| **Data Analytics (DA)** | Module-wise DA assessments |
| **Data Science (DS)** | Module-wise DS assessments |

---

### ⚙️ 2. Automated Calculations

- 📐 Average marks are calculated using **Function Nodes** in n8n  
- 🛡️ Ensures:
  - Accurate calculations  
  - No human errors  
  - Consistent data processing  

---

### 🔍 3. Eligibility Evaluation Logic

Eligibility is evaluated using **IF Nodes** with the following logic:

| 📊 Average Marks | 🎯 Eligibility Status | 📝 Feedback |
|-----------------|----------------------|-------------|
| **Above 70** | ✅ Eligible for Placement | Encouragement message |
| **70 or below** | ⚠️ Not Eligible | Improvement suggestions |

---

### 📩 4. Instant Automated Notifications

Students automatically receive **personalized messages** containing:

- 📊 Their **average score**  
- 🎓 **Placement eligibility status**  
- 💡 **Suggestions for improvement** (if not eligible)

---

## 🛠️ Skills & Tools Used

| 🔧 Tool / Skill | 💬 Description |
|----------------|---------------|
| **n8n Workflow Automation** | Core automation platform |
| **n8n Forms** | Collect student marks |

| **Function Nodes** | Average marks calculation |
| **IF Nodes** | Eligibility decision logic |
| **Automation Triggers** | Workflow execution |
| **Automated Notifications** | Instant student feedback |

## 🚀 Impact of the Project

This automation solution:
